# 发布包使用

完整解压到可写目录，打开根目录`AzurPilot-Local.exe`。点击「启动」，选择网页端或桌面端；首次使用准备部署设置并进入首页，创建或导入实例后使用。移动目录后自动修正Python路径，已有用户实例保持原样。

所有维护入口位于「更多选项」。接入官方更新使用「版本更新 → 检查更新 → 更新并重启」；新版本在独立目录完成构建和验收，再切换入口。上一版及其数据保留，可在同页回退。详细说明见 [安装与更新](INSTALL_UPDATE.md)。

视频和字体已经内嵌 EXE，不需要另放视频或安装字体。运行环境与模型随完整包提供，桌面端使用 WebView2。原官方启动器留在原备份中，日常使用根目录的本地版入口。

`source.bundle` 用于恢复固定源码记录，应随包保留。首次启动生成 `.git`、`config`、`cache` 属于正常行为。更新后还会生成 `.updates` 和 `versions`，个人完整备份需包含它们。

制作公开包时从当前版本导出到新空目录，排除用户数据、缓存与开发材料，按 [发布整理规则](RELEASE_EXPORT_RULES.md) 验证后再发布。
