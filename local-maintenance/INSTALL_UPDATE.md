# 安装、更新与备份

## 安装

完整解压到可写目录，打开根目录的`AzurPilot-Local.exe`，点击「启动」并选择网页端或桌面端。首次使用只准备版本记录与部署设置，然后进入首页；用户在首页创建或导入实例。移动目录后自动修正Python路径，不自动创建实例或重置已有配置。

## 更新上游

1. 在控制台正常退出，再打开启动器。
2. 进入「更多选项 → 版本更新 → 检查更新」。更新源为 `wess09/AzurPilot` 的 `master` 分支；本次检查得到的提交号会固定下来。
3. 点击「更新并重启」。程序依次备份数据、获取源码、合并本地修改、准备独立 Python 环境、构建前端、迁移配置和数据库，最后检查服务与页面。
4. 检查通过才切换版本并重新打开启动器，随后照常选择网页端或桌面端。

联网仅发生在手动检查和更新时。下载或构建失败可重试，旧版本继续保留；源码冲突需先按作业日志适配。Node 构建依赖保留在更新缓存，不进入应用版本目录，日常启动不需要 Node。

本地启动器、视频、字体、窗口与托盘、本地游戏修复会一并迁移。个人配置从备份副本迁移，三个等待、队列清空、停止调度器选项保留原值。更新验证不会启动游戏任务。

## 回退

进入「更多选项 → 版本更新 → 版本回退」，选择「回到上一版本」。回退使用上一版本及其当时的数据；更新后新增的数据仍保留在新版目录中。

## 备份离线版

1. 正常退出控制台和启动器。
2. 复制整个安装文件夹，保留 `.updates/current.json`、`versions`、运行环境和根目录 EXE。
3. 需要时在备份目录打开根目录 EXE，即可继续使用备份时的版本。

只备份个人数据时，使用「更多选项 → 恢复与检查 → 备份配置与数据」。备份位于 `.updates/backups`，包括当前配置、数据库与旧版业务记录。

## 目录说明

| 位置 | 用途 |
| --- | --- |
| 根目录 `AzurPilot-Local.exe` | 固定启动入口 |
| `.updates/current.json` | 当前与上一版本目录记录 |
| `versions/<版本>/` | 独立源码、运行环境、配置和数据 |
| `.updates/backups/` | 更新前与手动创建的数据备份 |
| `.updates/jobs/` | 更新记录、具体错误和命令输出 |
| `.updates/cache/`、`.updates/build/`、`.updates/tools/` | 下载与构建缓存 |
| `local-launcher/settings.json`、`local-launcher/data/` | 安装共用的启动偏好和桌面浏览器数据 |

没有当前版本记录时，直接使用根目录的原版本。「手动维护」仍保留旧的源码获取与分步修复入口，日常更新使用上面的自动流程。
