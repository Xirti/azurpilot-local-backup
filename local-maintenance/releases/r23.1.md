# AzurPilot 本地版 r23.1 · 统一启动器与手动更新

Windows x64 本地版，包含独立运行环境、识别模型和统一启动器。

### 主要功能

- 在启动器中选择网页端或桌面端，桌面端支持托盘与原有窗口操作。
- 手动检查并接入官方更新，自动备份数据，在独立目录构建、验证和切换，支持版本回退。
- 启动后进入首页，由用户创建或导入实例；外观可选跟随系统、浅色或深色。
- 提供启动日志、错误详情与日志导出，保留本地减负设置及大世界自律寻敌计时修正。
- 背景视频与启动器字体内嵌，无需单独安装字体。

### 本次调整

- 缩小右上窗口操作按钮。
- 取消启动交接时的强制置顶，淡入过渡保留其他窗口的遮挡关系。

### 使用

下载附件 `AzurPilot_Local-r23.1-Windows-x64.zip`，完整解压后打开 `AzurPilot_Local/AzurPilot-Local.exe`。首次启动自动准备本地环境，在首页创建或导入实例即可。系统需 Windows x64 和 WebView2 Runtime，模拟器画面使用 1280 × 720。

发行包不预置个人实例，不含测试脚本、私人配置、日志或浏览器记录。源码位于本 Release 对应标签，日常使用下载 Windows 整包。

已验证首次启动、网页端和桌面端、实例创建、系统明暗切换、托盘退出及窗口遮挡；整包文件清单与全部 CRC 校验通过。验证未运行游戏账号任务。
